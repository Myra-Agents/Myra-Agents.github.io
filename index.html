Myra Agents — Manage & Run your AI Agents
from anywhere

Each card carries a prompt. Launch it and Myra Agents spawns a headless CLI agent — Claude, OpenCode, Copilot CLI, or your own binary — streams its output live onto the card, and moves it through the workflow as the agent reports progress.

Star on GitHub Install →

Built for orchestrating agents

A board, a queue, and a scheduler around whatever CLI agent you already run.

▦

Kanban lifecycle

Draft → To Do → In Progress → Waiting Feedback → Awaiting Review → Done, driven by what the agent reports.

⚙

Per-card agent presets

Configure name, binary, and an args template with a {prompt} placeholder, plus a default working directory.

≣

Live streamed logs

Per-run output streamed onto the card, plus a history view with duration and — when reported — token / cost stats.

⇉

Run queue

A maxConcurrentAgents limit (0 = unlimited) — launches over the cap queue up and dequeue as agents finish.

⏱

Schedules

Once / daily / weekly / interval / cron, with a planner view. Runs in the background from the system tray.

⌂

Local-first

Runs fully on your machine against a bundled server sidecar. An optional managed cloud is opt-in via env vars — never required.

Also: English + French UI · best-of-N multi-agent (roadmap) · budget caps · card chaining (roadmap).

How it works

A card flows through lanes as its agent reports progress.

Draft To Do In Progress Waiting Feedback Awaiting Review Done
1 · Write

Add a card with a prompt, pick an agent preset and working directory.

2 · Launch

Myra spawns the agent headless and streams its output live onto the card.

3 · Move

The card advances through lanes as the agent reports — or schedule it to recur.

Get started

One command sets up the full dev workspace — clones every repo and wires it together.

curl -fsSL https://raw.githubusercontent.com/Myra-Agents/Myra-Agents-Dev/develop/install.sh | bash

Prereqs: bun, Rust toolchain + Tauri v2 prerequisites. Open-source contributors get a working app without private access.
