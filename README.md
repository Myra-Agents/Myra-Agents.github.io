# myra-agents.github.io

Landing page for **Myra Agents** — a local-first desktop Kanban board that runs
headless CLI coding agents.

🌐 **https://myra-agents.github.io**

Static single-file site (`index.html` + Tailwind CDN). No build step — GitHub
Pages serves the default branch root directly. Edit `index.html` and push.

App repo: https://github.com/Myra-Agents/Myra-Agents
